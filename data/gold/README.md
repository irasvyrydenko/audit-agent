# Gold data (committed)

Hand-labeled evaluation data. Small, versioned, never generated by the system under test
without manual review. Planned layout:

| Path | Content |
|---|---|
| `filing_loader/<TICKER>_<FY>.json` | per Item: expected start/end paragraph text |
| `kpi_extractor/overrides.json` | manual corrections where XBRL is wrong/missing (with reason) |
| `indicator_engine/hand_calcs.json` | hand-calculated indicators for a few company-years |
| `risk_detector/paragraphs.jsonl` | `{paragraph_id, ticker, fy, text, labels, split}` |
| `consistency_checker/claims.jsonl` | `{claim_id, paragraph_id, text, expected_verdict}` |
| `report_generator/manual_review.jsonl` | statement-level `supported: true/false` labels |

Record labeling guidelines and who labeled what in `docs/crisp_dm.md` (Data Preparation).
